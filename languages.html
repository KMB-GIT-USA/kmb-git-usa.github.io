Programming languages are a core part of computer science. These languages allow humans to direct and translate logical ideas into executable instructions for a computer. There are hundreds of languages, ranging from high-level, which is easier for humans to read, to low-level, which is closer to the instructions a computer would receive. These languages each serve different purposes, some are for databases like SQL, some structure webpages like HTML, and others like Python or Java are for general application development and scripting. Each language generally has its ups and downs leaving programmers to decide which is best fit for a particular project.
